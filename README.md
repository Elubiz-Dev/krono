# Krono® (@krono.ibg) — Landing Page E-Commerce

Landing page ultra-rápida y de alta conversión para **Krono** (@krono.ibg), tienda especializada en relojería robusta tipo Invicta en Ibagué, Tolima y despachos a toda Colombia.

## 🚀 Características
- **Arquitectura de conversión:** Inspirada en Container Of Time y $P Company.
- **Canal de venta:** Integración directa con WhatsApp (atención personalizada 1 a 1 y pedidos en 1 clic).
- **Catálogo & Combos:**
  - Combo Principal $85.000 COP (Reloj + Estuche de Lujo Rígido + Pila de Repuesto sellada).
  - Combos Emprendedor / Mayoristas (Lotes x3, x5 y x10 unidades).
- **Tecnologías:**
  - React 19 + Vite
  - CSS Vanilla puro con diseño oscuro de lujo (Obsidiana × Champagne Gold)
  - Partículas animadas en Canvas
  - Sonidos de feedback háptico/auditivo con Web Audio API
  - Confetti dinámico en pedidos
  - 100% Mobile-First y optimizado para SEO

## 🛠️ Instalación y Desarrollo Local

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build
```
